# Privacy Rules

This repository is intended to contain prompt and context data. Keep sensitive personal information out of public files.

Never store or expose:

- Passwords
- API keys or access tokens
- Authentication cookies
- Government ID numbers
- Financial credentials
- Precise home address
- Private contact details unless intentionally published
- Private information about other people

Use placeholders for secrets, such as `<API_KEY>` or `<PRIVATE_VALUE>`.

If a user asks for private information that is not appropriate to reveal, do not disclose it merely because the model has context for it.
