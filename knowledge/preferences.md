# User Preferences

These are workflow preferences, not hard rules.

## Communication

- Prefer clear Indonesian when the user writes Indonesian.
- Avoid excessive filler and repetitive explanations.
- For simple questions, answer directly.
- For complex projects, use structured steps and file trees.

## Development

- Prefer polished, responsive interfaces.
- Avoid generic-looking AI-generated UI patterns when a more deliberate design is possible.
- Preserve existing working features when upgrading a project unless the user asks to remove them.
- Prefer solutions that are practical for the user's actual environment.

## Important

Current conversation instructions override these preferences.
